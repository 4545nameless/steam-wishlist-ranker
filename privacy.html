プライバシーポリシー

最終更新日: 2026年10月21日

Steam Wishlist Ranker（以下「本サイト」）は、利用者の情報を次のとおり取り扱います。

1. 入力される情報とその扱い

本サイトでは、ウィッシュリストの取得のために SteamID64 と Steam Web API キーを入力します。これらと、ランキングの途中経過・結果は、利用者のブラウザ内（localStorage）に保存されます。運営者が利用者の情報を収集・保存するためのデータベースは持っていません。

ウィッシュリストや所持ゲームの取得時には、入力された SteamID64 と API キーが、Steam API へのリクエストを中継するサーバー（Cloudflare Workers）を経由して Steam に送信されます。この中継は取得処理のためだけに行われ、中継サーバーのログ収集は無効化されており、運営者がこれらの情報を保存・記録・利用することはありません。

2. 広告について

本サイトでは、第三者配信事業者である Google が提供する広告サービス「Google AdSense」を利用する場合があります。Google などの第三者配信事業者は、Cookie を使用して、利用者が本サイトや他のサイトに過去にアクセスした際の情報に基づいて広告を配信することがあります。

Google による広告 Cookie の使用は、広告設定で無効にできます。詳しくは Google の広告に関するポリシーをご覧ください。

3. 寄付について

本サイトには、運営を支援するための任意の寄付リンク（Ko-fi）があります。寄付の決済や情報の取り扱いは、Ko-fi および決済事業者のポリシーに従います。

4. 外部サービスの利用

本サイトは、画像生成のために html2canvas(unpkg 経由)を、アクセス状況の把握のために Vercel Analytics を、ゲーム情報や画像の取得のために Steam の各種サービスを利用します。Vercel Analytics は Cookie を使わずにアクセス統計を収集します。

5. 免責事項

本サイトは Valve Corporation および Steam とは無関係の非公式ツールです。本サイトの利用により生じた損害について、運営者は責任を負いません。

6. ポリシーの変更

本ポリシーは、必要に応じて内容を変更することがあります。変更後の内容は、本ページに掲載した時点から効力を持ちます。

7. お問い合わせ

本サイトに関するお問い合わせは、運営者の Ko-fi ページ（こちら）からお願いします。
