更新履歴

Steam Wishlist Ranker のこれまでの主な更新です。新しい順に並べています。小さな修正は省いています。

2026年10月

10月31日

  • 新しいアドレス（steam-wishlist-ranker.pages.dev）に移転しました。ランキングはアドレスごとにブラウザへ保存されるため、前のアドレスで作ったランキングは引き継げません。お手数ですが、もう一度読み込んでください。
  • 遊び方ガイド、よくある質問、記事5本、運営者情報、利用規約のページを追加しました（日本語と英語）。

10月28日

  • ウィッシュリストやプロフィールのアドレスを貼るだけで始められるようにしました。SteamID64 を自分で調べる必要がなくなりました。

10月27日

  • 並べた結果を、Steam のウィッシュリストの「カテゴリ」として付けられるようにしました（🔥今すぐ欲しい／🏷️セールなら買う／💭いつか買うかも／🗑️たぶんいらない）。使い方は記事「カテゴリと通知で、セールの見逃しと買いすぎを減らす」にまとめています。
  • 読み込み直したときに、前回のランキングを残したまま、新しく追加したゲームだけを差し込めるようにしました。
  • 結果画面の区切りの名前を、カテゴリと同じ名前にそろえました。
  • X のフォローと、お問い合わせ先へのリンクを追加しました。
  • 不具合を直しました：シェア画像の表示の崩れ、英語の文の空白抜け、上位をもう1ラウンド比べたときに中位と下位の並びが崩れる問題。

10月26日

  • ゲームの情報をまとめて取得するようにして、読み込みを速くしました。274本のウィッシュリストで、数十秒かかっていたのが数秒になりました。
  • 発売前のゲームの発売日を、Steam のストアと同じ表示（年だけ・年月・四半期など）にそろえました。

10月25日

  • 結果画面でゲームをドラッグしているあいだも、ページがスクロールするようにしました。

10月24日

  • 遊び方を作り直しました。気になるゲームをタップ → 4本から選ぶ → 上位は1対1 → 決勝トーナメント、の順に絞り込みます。下位のゲームが上位に挑戦する「乱入戦」も入りました。詳しくは遊び方ガイドと、記事「ランキングの仕組み」にあります。
  • 決勝のあとの仕上げとして、「中位整理」と、一番いらないゲームを決める「最弱決定戦」を追加しました。
  • Steam の Web API キーを入力しなくても使えるようにしました。
  • ブックマークを1回押すだけで、Steam のウィッシュリストに順番を反映できるようにしました。スマホ用の手順も用意しました。
  • Steam での過去最安値（IsThereAnyDeal のデータ）を表示するようにしました。
  • ストアの価格を、住んでいる国の通貨で表示するようにしました。
  • 結果を4つの区切りに分けて表示し、ドラッグで順番を直せるようにしました。キーボードでも操作できます。
  • シェアの投稿文と画像を作り直しました。
  • ロゴを作りました。
  • スマホで結果の表が切れる問題を直しました。

10月22日

  • 4本の中から「一番欲しい」と「一番いらない」を選ぶ方式を追加しました。1対1だけで比べるより、ずっと速く並べられます。
  • 選んだときの紙吹雪などの演出を追加しました。

10月21日

  • 6つの言語（日本語・英語・中国語・ロシア語・ポルトガル語・ドイツ語）に対応しました。
  • プライバシーポリシーを公開しました。
  • SteamID64 の調べ方と、Steam に反映する手順の説明を追加しました。
  • X にシェアするときに、画像のコピーがうまくいかない問題を直しました。

10月20日

  • Steam Wishlist Ranker を公開しました。ウィッシュリストのゲームを1対1で比べて、ランキングを作れる最初の版です。

不具合の報告や要望は、お問い合わせからお寄せください。
